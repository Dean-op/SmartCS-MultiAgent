## 1. 最终目标

从 0 实现一个：

> **Python + FastAPI + LangGraph + PostgreSQL + Redis + Milvus 的企业级电商 Multi-Agent 系统**

最终具备：

```text
订单查询
物流查询
退款处理
企业知识库 RAG
Multi-Agent 编排
Memory
Human-in-the-loop
安全控制
Evaluation
Observability
```

学习策略：

```text
理解必要概念
    ↓
理解为什么项目需要它
    ↓
设计模块
    ↓
由 Codex 实现
    ↓
运行测试
    ↓
理解运行结果
    ↓
Code Review
    ↓
进入下一模块
```

我们不追求：

> “代码每一行都能默写。”

而追求：

> “架构、数据流、调用关系、关键技术决策能够解释清楚。”

| 类型             | 技术             |
| -------------- | -------------- |
| 语言             | Python 3.12+   |

注意三个数据库职责：

```text

```

绝对不要混淆。

## M10：Hybrid Search + Reranker

预计：**5～6h**

这是我们的**第一个重点简历优化模块**。

### 学什么

理解三种东西：

### Dense Search

擅长：

```text
语义
```

例如：

```text
我买的东西坏了怎么办
```

可以匹配：

```text
商品质量问题售后政策
```

---

### Sparse / BM25

擅长：

```text
精确关键词
型号
数字
专有名词
```

---

### Hybrid Search

组合：

```text
Dense
+
Sparse/BM25
```

Milvus 原生提供 Hybrid Search 能力，因此无需额外部署 Elasticsearch。Milvus 2.6 官方文档也将 Hybrid Search 作为标准检索能力。

### 再学习

```text
RRF
Reranker
Recall@K
```

只建立正确认知，不深入论文。

### 最终 Pipeline

```text
Query
 │
 ├── Dense
 │
 └── Sparse / BM25
       ↓
 Hybrid Search
       ↓
      RRF
       ↓
    Reranker
       ↓
      Top-K
```

### 完成标准

自己跑实验：

```text
Dense only

VS

Hybrid Search

VS

Hybrid + Reranker
```

比较：

```text
Recall@K
```

这将成为简历真正的数据支撑。

# 5. 我们每个模块固定怎么学

以后每个模块严格使用同一套流程。

## Step 1：知识讲解

我先解释：

```text
它是什么？

解决什么问题？

为什么我们的项目需要？

它在整个架构里的位置？

与类似概念有什么区别？
```

只讲项目需要的深度。

---

## Step 2：画数据流

例如 Tool：

```text
Agent
 ↓
Tool
 ↓
Service
 ↓
Repository
 ↓
PostgreSQL
```

你需要先看懂，再让 Codex 写。

---

## Step 3：确定设计

我们一起确定：

```text
输入
输出
职责
依赖
边界
```

---

## Step 4：我生成 Codex Prompt

每次 Prompt 都包含：

```text
Context

Goal

Architecture

Current State

Requirements

Constraints

Files

Acceptance Criteria

Tests

Do Not
```

不会简单写：

> “帮我实现 XXX。”

---

## Step 5：Codex 实现

Codex 负责：

```text
创建代码
修改代码
写测试
运行测试
修复错误
```

---

## Step 6：验收

不是：

```text
代码没报错
= 完成
```

而是：

```text
功能正确
+
测试通过
+
架构符合设计
```

---

## Step 7：学习复盘

每个模块完成后，你至少应该能回答：

```text
① 这个模块解决什么问题？

② 为什么采用这个设计？

③ 它和上下游模块怎么交互？

④ 有没有替代方案？

⑤ 面试官最可能追问什么？
```

不要求背代码。
